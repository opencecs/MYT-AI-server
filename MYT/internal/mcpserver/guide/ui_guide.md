# MYT 客户端界面元素字典

本文档供通过 MCP 操作客户端 UI 的 AI 查阅，描述每个页面、区域、元素的作用。出处为前端源码文件:行号（`MYT/frontend/src/` 下）；i18n 文案为 zh-CN 原文；标注「v2 砍」表示 V2 部署模式下该元素被移除。

> 群控页说明：pages/groupcontrol 的 GroupControlPage 为死代码（App.tsx tabs 无此项、全仓无引用），唯一存活组件 CreateGroupModal（新建分组弹窗）归入设备侧栏；i18n 残留 nav.groupcontrol:「群控」键无对应 tab。

### 1.5 弹窗内部详述

**ScreenCastModal（启动器，非常规弹窗）**（pages/host/screencast/ScreenCastModal.tsx）— 无常规 UI，打开即执行，无论成败最终 onClose：

- **执行逻辑**（:17-36）— IsProjectionRunning(ip,slot) 已投屏则 BringProjectionToFront 置前，否则 StartBatchIndividualProjections 单台启动（scale=1.0 原始大小居中、默认带侧边栏）
- **成功态**（:51）— return null（不渲染任何 UI）
- **启动失败浮层**（:38-48）— 仅此时右下角错误浮层 +「关闭」按钮（host:screencast.close）
- **投屏设置**（GPU 加速开关/侧边栏开关）— 在 ScreencastSettingsModal（pages/host/components/ScreencastSettingsModal.tsx:47-81，遮罩 z-50 点遮罩关闭）

**TerminalModal**（pages/host/terminal/TerminalModal.tsx）：

- **遮罩/面板**（:169-170）— 遮罩 bg-black/50 z-50；面板 90vw max-1000px 75vh 深色
- **标题**（:175）— 「终端 - {{title}}」，title=displayName 优先
- **状态徽标**（:176-179）— 连接中(黄)/已连接(绿)/已断开(红)/出错(红，显示具体 error)
- **关闭方式**— ×（:174）与「关闭」按钮（:181-184）是仅有的关闭方式——无 Escape、遮罩无点击
- **终端区**（:187）— xterm canvas
- **【行为】** 断开/出错后 3 秒自动关窗（useTerminalSession.ts:70-72）；选中文本自动复制（:91-96）；Ctrl/Cmd+C/V 粘贴清洗零宽字符（:98-122）；连接成功按真实尺寸校正 PTY（:158-164）
- **【行为·模式差异】** local/public 走设备 SDK WS ws://{ip}:8000/link/exec（:88，密码 localStorage devicePasswords → GetDevicePassword 兜底 :89-108，30s 心跳 :118-120）；v2 走容器 ADB 直连 V2Service.OpenV2Terminal（:178），deviceIP 为序列号
